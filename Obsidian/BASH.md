pwd --- print working directory 
cd --- change directory 
ls -- list the files in the directory 
mkdir ---- make directory
touch --- creates a file 
cat ---- used to see the contents of the file inside the terminal 
vi --- used to open the vim inside the terminal
mv ---- move 
cp ---- copy 

```bash
mv new_fold1 test2
mv a2.txt test2

cp a2.txt test2
cp -r new_fold1 test3 
// when we are copying over folders
```

nvm --- node version manager
node ---- node version

terminal is another interface to do things in your machine
