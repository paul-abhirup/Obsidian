🧠 NeuroScan-360 Web App — v0 UI Design Guidelines

📌 OVERVIEW:
This web app supports neuro-cognitive tests for Parkinson’s/dementia patients. UI must be:
- Clean and minimal
- Visually accessible
- Touch/stylus-friendly
- Professional, but friendly

🎨 COLOR SCHEME:

Base Theme: Calm Blue-Green Clinical Theme

• Primary Color: #2E8BC0 (Calm Blue)
• Secondary Color: #145DA0 (Dark Blue)
• Accent Color: #00B8A9 (Teal)
• Background Color (Light Mode): #F6F9FB (Soft White)
• Background Color (Dark Mode): #1F2F3F
• Border/Divider: #DDEAF1
• Error: #FF4C4C (Red)

🧩 Color Roles:
- Primary: Buttons, titles, progress bar
- Secondary: Button hover, subtitles
- Accent: Highlights, status indicators
- Background: Container bg, card bg
- Error: For invalid input or failure

🖋️ TYPOGRAPHY:

• Headings: Montserrat, Semibold (if available), else Sans-serif
• Body: Roboto or Arial
• Sizes:
  - H1: 28–32px
  - H2: 24px
  - Body: 16–18px
  - Small Text: 12–14px
• Line Height: 1.5x font-size
• Letter spacing: slight increase on headings

📐 UI ELEMENTS:

• Button Style:
  - Rounded corners (8–12px)
  - Hover: Light shadow + secondary color
  - Pressed: Darker tone of primary
  - Font-weight: medium-bold

• Cards/Panels:
  - Rounded corners (12px)
  - Soft shadow (2–4px blur)
  - Padding: 20–24px

• Inputs:
  - Large, clearly labeled
  - Use placeholder + labels
  - Outline highlight on focus

• Video Container:
  - Full-width responsive box
  - Optional dark blur background during playback

🌈 ACCESSIBILITY:

• Contrast Ratio: Minimum 4.5:1 for text
• Font Resize: Responsive text scaling (support up to 200%)
• Button size: Minimum 44x44px for touch screens
• Colorblind-friendly palette (avoid red/green-only states)

🎬 ANIMATIONS:

• Button click: Soft bounce scale (0.95x → 1.0x)
• Section transitions: Fade or slide
• Page load: Optional logo reveal with fade-in

📱 RESPONSIVE DESIGN:

• Must work on:
  - Desktop (1280px+)
  - Tablet (768–1024px)
  - Mobile (360–768px)
• Use grid or flex layout
• Avoid clutter – one focus per screen

📷 ICONS & GRAPHICS:

• Use flat-style icons (Lucide, Heroicons, or Material)
• Keep visuals minimal but meaningful
• Clock, brain, pen, tablet icons may be used

📂 COMPONENTS TO DESIGN:

• Welcome / Instruction page
• Video playback area
• Drawing result viewer (score, pressure)
• Result summary card
• Retry / Home buttons
• Patient header/info bar

📌 REMARKS:
- Keep the UI empathetic and calm
- Avoid harsh color contrasts or visual clutter
- Support slow/intermittent input for elderly patients
